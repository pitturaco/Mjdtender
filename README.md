# منصة عطاءات ومناقصات غزة الشاملة

## البنية
- `public/index.html`  الموقع (واجهة الجوال)
- `api/source.js`      السيرفر الذي يقرأ المواقع (jobs.ps وpal-arc.org وpalestinetenders.com)
- `vercel.json`        مدة تشغيل الدالة 30 ثانية

## التركيب على tendergaza.vercel.app
1. افتح مستودع GitHub المرتبط بمشروعك في Vercel (أو أنشئ واحداً وربطه بالمشروع من Vercel).
2. احذف الملفات القديمة وارفع هذه الملفات الأربعة بنفس المجلدات.
3. Vercel يعيد النشر وحده خلال دقيقة.

## إضافة موقع جديد
في `api/source.js` أضف سطراً داخل `SOURCES` (اسم الموقع، رابط القائمة، نمط روابط الإعلانات)،
ثم أضف اسمه المختصر إلى `SRCS` في `public/index.html`.
